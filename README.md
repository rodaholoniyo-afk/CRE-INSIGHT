
# CRE Insight — Commercial Real Estate Dashboard

## Project Overview

CRE Insight is a beginner-level web development project that combines
basic commercial real estate underwriting with virtual assistant task
management in a single dashboard.

The application demonstrates how HTML, CSS, and JavaScript can be used
to create an interactive tool for property analysis, task organization,
and document tracking.

## Project Objectives

- Develop a simple and user-friendly dashboard.
- Calculate Net Operating Income (NOI) and capitalization rate.
- Create and manage administrative tasks and deadlines.
- Track property-related documents and their statuses.
- Display summary statistics for properties, analyses, tasks, and documents.
- Practice fundamental frontend web development skills.

## Technologies Used

- HTML5 — Page structure and forms.
- CSS3 — Styling and responsive layouts.
- JavaScript — Calculations, validation, and interactive features.
- Browser localStorage — Local data persistence.

## Main Features

1. Dashboard overview with summary cards.
2. Property underwriting calculator.
3. Virtual assistant task manager.
4. Property document tracker.
5. Automatic dashboard updates.
6. Local storage for saved records.

## How to Run the Project

1. Download or copy the project files into a folder named `cre-insight`.
2. Ensure the folder contains:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Open `index.html` in a modern web browser.
4. For development, you can use Visual Studio Code with the Live Server extension.
5. Enter property details, add tasks, and record documents to test the application.

## Financial Formulas

Net Operating Income (NOI):

NOI = Annual Rental Income - Annual Operating Expenses

Capitalization Rate:

Cap Rate = (NOI / Purchase Price) * 100

## Project Scope and Limitations

This is a frontend demonstration prototype intended for educational
purposes. It does not include user authentication, a backend server,
or a shared database.

Records are stored locally in the browser. They are not synchronized
between users or devices. Clearing browser storage may remove saved data.

The financial calculations are simplified and are not investment advice.
